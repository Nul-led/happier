Happier drives **Antigravity** over ACP. Happier sessions run against Google's
official `agy_acp_server`, which Happier installs and manages for you. The
interactive `agy` CLI is a separate surface — Happier uses it for the terminal
and for discovering existing CLI conversations, not for its own sessions.

## Requirements

For Happier sessions, nothing to install by hand. Happier downloads the pinned
Antigravity ACP server the first time you select Antigravity, verifies it
against a pinned SHA-256, and reuses the cached copy afterwards. Google
publishes it for macOS (Apple silicon), Linux (x64 and arm64) and Windows (x64
and arm64); there is no Intel-macOS build, so that combination is reported as
unsupported rather than emulated.

For the **terminal** surface and external-session discovery you also need the
Antigravity CLI installed locally:

- `agy` available on `PATH`, or `HAPPIER_ANTIGRAVITY_PATH` set to its absolute path

The binary is called `agy`, not `antigravity`, which is the usual reason a
working install looks missing.

## Install the Antigravity CLI

Happier ships the vendor's own install recipe and can run it for you from
**Settings → Agents → Antigravity**. When Happier drives the install it asks
first — running a vendor script is not something it will do silently.

In unreleased 0.3 development builds, this install runs as one daemon job on the
selected machine, with steps for the `agy` CLI, the managed ACP server, and a
final CLI check. See [install and update jobs](/agents#install-and-update-jobs-in-03-development)
for reconnecting, progress, and cancellation limits.

To install it yourself:

```bash
curl -fsSL https://antigravity.google/cli/install.sh | bash
agy --version
```

On Windows, in PowerShell:

```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```

Google's own instructions are at
[antigravity.google/docs/cli-install](https://antigravity.google/docs/cli-install).

## Authentication

Happier sessions authenticate the managed ACP server, independently from the
interactive `agy` CLI. From **Settings → Agents → Antigravity**, Happier opens
the ACP server's provider-owned browser login on the selected machine. The same
plugin-declared flow is available from a shell:

```bash
happier agents auth login antigravity
```

Wait for the command to confirm completion before starting a session. Signing
in through the interactive `agy` CLI alone does not authenticate Happier's ACP
server.

Happier does not probe Antigravity's login state in the background — the agent
exposes no safe non-interactive signal — so the status may read **Unknown** even
when you are signed in. Use **Check now** after logging in.

You can also attach a Gemini Connected Account to Antigravity to supply model
credentials to the ACP server.

## What Happier can drive

- **Model selection** is supported.
- **Resume** is supported through Antigravity's own session state.
- **Session modes** are not exposed to Happier, so there is no mode picker.
- **Handoff, listing and forking** are not supported.

## Terminal and existing CLI conversations

The terminal surface launches the interactive `agy` CLI on the selected machine.
Happier also observes Antigravity CLI transcripts so existing conversations show
up as external sessions you can read.

ACP sessions and `agy` CLI conversations are **separate identities**. Opening the
terminal from a Happier ACP session starts a fresh `agy` conversation rather than
reattaching to the ACP one, and external CLI sessions are read-only — Happier
does not claim writer safety or takeover for them.

The full matrix is on [Agent capabilities](/agents/capabilities).

## Troubleshooting

### "Antigravity not found"

Check the binary name — it is `agy`:

```bash
agy --version
```

If it is installed somewhere off `PATH`, point Happier at it directly:

```bash
export HAPPIER_ANTIGRAVITY_PATH=/absolute/path/to/agy
```

Happier ignores an override that does not point at an executable file, falling
back to `PATH` rather than reporting an error — so a typo here looks exactly
like no override at all.

### "Authentication required"

Run `happier agents auth login antigravity` on the agent machine, or open the
login flow from **Settings → Agents → Antigravity**. Keep the flow open until it
reports completion; the ACP server owns browser login and credential storage.
